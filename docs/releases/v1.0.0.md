# Live AI Terrarium v1.0.0 Release Notes

## Summary

`v1.0.0` is the first proof-gated release of Live AI Terrarium.

This release delivers the local-first Milestone 1 contract:

- one Glass-Box runtime boundary with no direct sandbox network and no sandbox secrets
- one shared command contract across API, CLI/TUI, and Streamlit
- one shared read model for run summary, cycle detail, audit state, and recovery state
- deterministic gate-first evaluation and proof-grade evidence capture
- evidence-preserving branch-and-continue and manual rollback workflows
- a completed ten-cycle proof harness with browser validation evidence

## What Is In v1.0.0

### Runtime and boundary

- Hardened runtime registration with `network_mode="none"`, zero published ports, and one workspace mount.
- One sanctioned sandbox artifact egress path at `/workspace/.gb/outbox`.
- Host-controlled state and backup roots under `%LOCALAPPDATA%/LiveAITerrarium/`.
- Host-side model gateway binding that keeps credentials and allowed-model policy outside the sandbox.

### Control and audit

- Canonical operator action set: `observe`, `mode switch`, `pause`, `resume`, `branch`, `clone`, `reset`, `rollback`.
- Shared allow-or-deny dispatch with idempotency handling and observation-only fail-closed behavior.
- Approval-backed mode-switch receipts and append-only SHA-256 chained audit ledger.

### Evidence and recovery

- Run-start reproducibility manifest with immutable build identity.
- Brokered append-only full-log capture for proof cycles.
- Cycle-to-audit linkage for proof consumers.
- Recovery controller flows for branch-and-continue, manual rollback, and kill-and-restore.

### Operator surfaces

- FastAPI adapter over the shared read and command paths.
- Typer `gb` CLI and Rich TUI over the same command and read models.
- Streamlit dashboard controller and renderer over the same shared backend path.
- Streamlit preview harness used for browser validation evidence.

## Milestone 1 Release Gate

The release gate is satisfied by the current evidence set:

- ten stable cycles complete
- zero unrecoverable failures in the proof loop
- full logs preserved
- rollback to the last accepted stable state verified
- per-cycle diff, score, and decision visibility available
- reversibility evidence includes branch-and-continue and manual rollback evidence

## Notes

- Sandbox-inner branch-and-continue evidence remains mirrored evidence only; it is not outer repository history.

- The Streamlit browser evidence was captured through `src/live_ai_terrarium/adapters/dashboard/preview_app.py`, which exists to validate proof-critical dashboard flows against canonical proof-shaped data.
