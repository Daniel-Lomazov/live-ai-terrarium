# Live AI Terrarium v1.0.1 Release Notes

## Summary

`v1.0.1` is a public-facing maintenance release on top of the proof-backed `v1.0.0` baseline.

It does not change the Milestone 1 proof contract. It packages the repository more cleanly for public usage by aligning version metadata, improving the root-facing documentation, and synchronizing active release guidance with the current GitHub state.

## What Changed

### Public entry points

- Added a root `README.md` with setup, validation, preview-launch, and code-navigation guidance.
- Updated repository-facing guidance so the release and milestone docs describe the current tagged state instead of future release intent.

### Version synchronization

- Bumped package metadata to `1.0.1` in `pyproject.toml`.
- Bumped the exported package version in `src/live_ai_terrarium/__init__.py`.
- Bumped the advertised FastAPI app version in `src/live_ai_terrarium/adapters/api/app.py`.

### Sample and preview consistency

- Updated the Streamlit preview manifest and the touched tests to surface `v1.0.1` as the visible sample release tag.

## Proof Baseline

The underlying proof baseline remains the one established by `v1.0.0`:

- ten stable cycles complete
- zero unrecoverable failures in the proof loop
- rollback and reversibility evidence verified
- browser validation evidence preserved

For the original proof-backed release bundle, see:

- `docs/milestones/m1-proof-checklist.md`
- `docs/releases/v1.0.0.md`
- `docs/test-evidence/browser-dashboard-validation.md`
- `docs/test-evidence/browser-dashboard-visual-baseline.md`
